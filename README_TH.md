# ANNA HAIR CARE — ชุดไฟล์โครงงาน

ชุดนี้เป็นต้นแบบร้านขายแชมพูสำหรับโจทย์ Landing Page + Google Sheets + GitHub + ระบบหยิบ/แพ็ก/จัดส่ง + Vercel

## ไฟล์ในโฟลเดอร์
- `index.html` — เว็บไซต์หน้าร้านและหน้าจัดการคำสั่งซื้อ
- `images/` — โฟลเดอร์สำหรับเก็บรูปสินค้าแยกจากไฟล์เว็บไซต์
- `google-apps-script/Code.gs` — โค้ดเชื่อม Google Sheets
- `sheets-template.csv` — ตัวอย่างตารางสินค้า
- `README_TH.md` — คู่มือภาษาไทย

## สินค้าตัวอย่าง 2 SKUs
- SH001 แชมพูสมุนไพร 159 บาท
- SH002 แชมพูอาร์แกนออยล์ 199 บาท

หมายเหตุ: ชื่อสินค้า ราคา และจำนวนสต็อกเป็นข้อมูลสมมติสำหรับสาธิต ควรแก้ให้ตรงกับสินค้าจริง/โจทย์อาจารย์

## A. ทดลองเว็บไซต์ก่อน
เปิด `index.html` ในเบราว์เซอร์ได้โดยดับเบิลคลิกไฟล์
- เพิ่มสินค้าเข้าตะกร้า
- กรอกชื่อลูกค้า เบอร์โทร และที่อยู่
- กดยืนยันคำสั่งซื้อ
- เปิดส่วน “จัดการออเดอร์” เพื่อดูใบหยิบสินค้าและข้อมูลแพ็ก
- โหมดนี้บันทึกข้อมูลในเบราว์เซอร์เครื่องเดิมเท่านั้น ยังไม่ใช่ Google Sheets

## B. ตั้งค่า Google Sheets จริง
1. เข้า Google Drive แล้วสร้าง Google Sheet ชื่อ `ANNA HAIR CARE ORDERS`
2. ไปที่ Extensions > Apps Script
3. เปิดไฟล์ `google-apps-script/Code.gs` ในชุดนี้ คัดลอกทั้งหมดไปวางทับ `Code.gs`
4. กด Save
5. เลือกฟังก์ชัน `setupSheets` แล้วกด Run ครั้งแรก จากนั้นอนุญาตสิทธิ์ตามหน้าจอ
6. กลับไป Google Sheet ต้องเห็นแท็บ `Orders` และ `Products`
7. ใน Apps Script กด Deploy > New deployment
8. เลือกประเภท Web app
9. Execute as: Me
10. Who has access: Anyone (ใช้เพื่อสาธิตในงานเรียนเท่านั้น; อย่าใช้กับข้อมูลลูกค้าจริงโดยไม่มีมาตรการรักษาความปลอดภัย)
11. กด Deploy และคัดลอก Web app URL ที่ลงท้ายด้วย `/exec`
12. เปิด `index.html` ด้วยตัวแก้ไขข้อความ แล้วหา `const API_URL=""`
13. วาง URL ระหว่างเครื่องหมายคำพูด เช่น `const API_URL="https://script.google.com/macros/s/รหัสของคุณ/exec";`
14. บันทึกไฟล์และอัปโหลด `index.html` เวอร์ชันแก้ไขกลับ GitHub

ข้อควรรู้: เมื่อเชื่อม API แล้ว คำสั่งซื้อใหม่และสถานะจะถูกส่งไป Google Sheets; ทดสอบด้วยข้อมูลสมมติก่อนใช้งานจริง

## C. อัปโหลดขึ้น GitHub
1. เข้า Repository `anna-hair-care`
2. กด Add file > Upload files
3. ลาก `index.html`, `README_TH.md`, `sheets-template.csv` และโฟลเดอร์ `images` เข้าไป (ถ้าอัปโหลดโฟลเดอร์ไม่ได้ ให้เปิดโฟลเดอร์แล้วอัปโหลดไฟล์รูปด้านใน หรือสร้าง `images/README.txt`)
4. สร้างโฟลเดอร์ `google-apps-script` ใน GitHub แล้วอัปโหลด `Code.gs` เข้าไป
5. กด Commit changes

## D. เผยแพร่ด้วย Vercel
1. เข้า https://vercel.com/ وسมัคร/Sign up ด้วย GitHub
2. اختر Add New > Project
3. Import Git Repository แล้วเลือก `aunnasai-web/anna-hair-care`
4. Framework Preset เลือก Other (หรือปล่อยค่าเริ่มต้น)
5. กด Deploy
6. รอจนสำเร็จ แล้วเปิดโดเมน `.vercel.app` ที่ระบบให้
7. ทดลองสั่งซื้อและตรวจหน้า fulfillment

## E. ขั้นตอนการทำงาน (Workflow)
1. ลูกค้าเลือก SKU และจำนวนสินค้า
2. ลูกค้ากรอกชื่อ เบอร์โทร ที่อยู่ และยืนยัน
3. ระบบสร้าง Order ID และบันทึกคำสั่งซื้อ
4. พนักงานดู Picking List เพื่อรวมจำนวนสินค้าที่ต้องหยิบตาม SKU
5. เปิดรายการออเดอร์เพื่อดู Packing/Delivery information
6. ตรวจ SKU และจำนวน ใส่กล่อง ปิดกล่อง และติดข้อมูลผู้รับ
7. เปลี่ยนสถานะตามลำดับ: รอหยิบสินค้า > หยิบสินค้าแล้ว > แพ็กสินค้าแล้ว > จัดส่งแล้ว

## ข้อจำกัด/สิ่งที่ต้องตรวจสอบ
- ระบบนี้เป็นโครงงานสาธิต ไม่ใช่ระบบชำระเงินหรือระบบขนส่งจริง
- ไม่มีการคำนวณค่าส่งหรือเชื่อมผู้ให้บริการขนส่ง
- รูปขวดบนหน้าเว็บเป็นภาพประกอบ CSS; สามารถเพิ่มภาพสินค้าจริงใน `images/` และแก้หน้าเว็บให้ใช้ `<img>` ได้
- Apps Script Web App ที่เปิดให้ Anyone เหมาะกับการสาธิตเท่านั้น ไม่ควรเก็บข้อมูลส่วนบุคคลจริงโดยไม่มีการป้องกัน
- ตรวจสอบข้อกำหนดของอาจารย์อีกครั้ง หากต้องใช้รูปสินค้าจริง/ชื่อโดเมนเฉพาะ/ฟิลด์อื่นเพิ่มเติม
